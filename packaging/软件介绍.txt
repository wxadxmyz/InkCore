================================================================
                   墨核 AI Studio (InkCore)
                一个装在自己电脑里的全能 AI 助手
                          版本 v1.0.0
================================================================


【一句话介绍】

  对话、写作、生图、联网搜索、跑代码、Agent 自动办事，
  全都在一个窗口里。API Key 和聊天记录只存你自己电脑上，
  不上传任何服务器。


----------------------------------------------------------------
【怎么启动】
----------------------------------------------------------------

  绿色版（本压缩包）：
    直接双击 InkCore.exe 即可，不用安装。
    建议先把整个文件夹解压到一个固定位置，
    路径最好不要带中文和空格。

  首次打开会看到引导页，按提示走完就能用。


----------------------------------------------------------------
【第一次用，先做这一步】
----------------------------------------------------------------

  软件需要一个"大脑"（AI 模型）才能聪明地干活。
  三个选择，任选其一：

  方案 A：用免费的云端模型（最快，推荐新手）
    1. 打开 https://siliconflow.cn 注册账号（送免费额度）
    2. 在网站里创建一个 API Key，复制下来
    3. 回到软件，点右侧「设置」
    4. 供应商选「SiliconFlow(免费聚合)」
    5. 把 Key 粘进去，保存
    完成，可以开始聊了。

  方案 B：完全离线，不联网也能用
    1. 点「设置」
    2. 供应商选「本地内置模型(离线·免Ollama)」
    3. 点启用，软件会自动下载约 1.1GB 的模型文件
    4. 下载完成后断网也能正常对话
    注意：首次下载需要联网，可能比较慢，耐心等。

  方案 C：已经有别家的 Key
    设置里支持 OpenAI、DeepSeek、通义千问、Moonshot、
    智谱 GLM、OpenRouter、Ollama、自定义接口，
    选对应的供应商填 Key 就行。


----------------------------------------------------------------
【能干什么】
----------------------------------------------------------------

  直接在输入框里说人话，软件会自动判断你要干嘛：

  写东西
    「写一段仙侠短篇，主角叫苏无尘」
    「帮我写一篇公众号文章：如何高效阅读」
    「来一个 3 分钟都市短剧脚本」
    「把上面这段改写得更口语化」

  画图
    「画一张赛博朋克小说封面」
    「给我一个古风少女的生图提示词」

  查资料
    「搜索今天 AI 领域的最新资讯」
    「把这段英文翻译成中文」

  干技术活
    「写一段 Python 并运行」   → 自动生成代码并全屏运行
    「打开终端，执行 ls -la」  → 自动唤起终端并全屏
    「帮我调研竞品整理成表格」 → Agent 自动拆步骤执行

  读文档
    右侧「知识库」上传 PDF / Word / TXT / Excel，
    然后直接问「总结这份合同的要点」。

  玩一玩
    右侧「离谱玩法」里有搓小游戏、清理电脑、讲笑话等，
    还能自己写 prompt 新建玩法，导出分享给朋友。


----------------------------------------------------------------
【界面怎么看】
----------------------------------------------------------------

  左边   —— 会话列表，可搜索、分组、重命名、删除
  中间   —— 对话主区域，支持多标签页同时开几个对话
  右边   —— 功能抽屉，点图标切换：
             写作助手 / AI 生图 / 提示词 / 记忆库 /
             知识库 / 技能 / 终端 / 代码运行 /
             Agent / 离谱玩法 / 设置

  小技巧：
   · 终端、代码、Agent、知识库、离谱玩法这五个面板，
     右上角有个「最大化」按钮，点一下铺满整个窗口，
     看长输出舒服很多。
   · 输入框上方有快捷按钮，点一下直接发送常用指令。
   · 生成过的图片和小游戏会钉在输入框上方，点开即回看。
   · 顶栏「编辑器」进入 Markdown 写作台，
     支持 AI 润色、七种格式导出。


----------------------------------------------------------------
【常用快捷操作】
----------------------------------------------------------------

  Ctrl + Alt + M     呼出 / 隐藏窗口（可在设置里改）
  点 🎤              语音输入，说话转文字
  点 📷              发图片让 AI 看图说话
  点 ⬇ 导出          存成 Word / PDF / Markdown / 公众号 HTML
  点消息旁的 ⟲       重新生成这条回复


----------------------------------------------------------------
【你的数据存在哪】
----------------------------------------------------------------

  全部在这个文件夹里：

     C:\Users\你的用户名\MoHeAI\

  里面有配置、聊天记录、记忆、技能、知识库文档、
  生成的图片、Markdown 笔记。

  想备份就整个复制走；
  想换电脑就把这个文件夹拷过去；
  软件里也有「备份 / 恢复」按钮可以一键导出。

  重要：API Key 只写在本地 config.json 里，
       不会发给除了你选的 AI 服务商之外的任何地方。


----------------------------------------------------------------
【常见问题】
----------------------------------------------------------------

  Q：Windows 提示"未知发布者"，是病毒吗？
  A：不是。这是因为没有购买代码签名证书。
     点「更多信息」→「仍要运行」即可。

  Q：不填 API Key 能用吗？
  A：能，会用内置模板引擎回复，但比较简单。
     想要真正的 AI 效果，还是建议配一个（有免费的）。

  Q：本地模型下载太慢？
  A：模型从国外服务器拉取，国内可能慢。
     可以先用免费的云端供应商，不着急下载。

  Q：终端功能会不会把我电脑搞坏？
  A：内置了危险命令黑名单（rm -rf、格式化等一律拦截），
     还有执行时长限制。设置里还能开「只读沙箱」，
     彻底禁止任何写操作。

  Q：怎么卸载？
  A：绿色版直接删文件夹就行。
     数据在 C:\Users\你的用户名\MoHeAI\，想清干净一起删。
